Опис проєкту

Навчальний проєкт, створений з метою повторити основний функціонал сайту інтернет магазину.
Проєкт реалізований на ASP.NET Core (бекенд) та React TypeScript (фронтенд) з метою практичного вивчення технологій розробки сучасних веб-додатків.

⚙️ Технології

⚙️ Backend (API)

ASP.NET Core 9
Entity Framework Core
PostgreSQL (або SQL Server)
AutoMapper
JWT Authentication
Swagger / OpenAPI
Dependency Injection

⚙️ Frontend

React 18 + TypeScript
Vite або Create React App
Redux Toolkit / RTK Query
React Router v6
Ant Design або Material UI
Axios / fetch API
